# JalRakshak 2.0
## Predictive Water-Intrusion Risk Detection and Pipe-Damage Localisation

JalRakshak 2.0 is a student software prototype designed to monitor water pipeline readings, identify unusual events, estimate suspicious pipeline sections, and help maintenance teams prioritise inspections.

### Features

- Simulated pressure and flow monitoring
- Three sensor nodes: A, B and C
- Pipeline section fault alerts
- Editable GPS coordinates
- Offline schematic pipeline map
- Pressure and flow trend chart
- Local alert history
- CSV report export
- Browser-based offline caching
- Planned ESP32 and LoRa integration

### Technologies

- HTML
- CSS
- JavaScript
- Browser Local Storage
- Service Worker API
